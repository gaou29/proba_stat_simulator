# Simulation de probabilités

## Prérequis

- Python 3.10 ou supérieur

## Installation

- creation environnement
```bash
python3 -m venv .venv
```

- activation environnement
 ```bash
 source .venv/bin/activate
 ```

- installation requirements
```bash
pip install -r requirements.py
```

## Lancer le projet

```bash
streamlit run app.py
```
